### Данный проект представляет собой комплексный анализ данных о транзакциях розничного магазина из датасета Superstore Dataset (Kaggle). Основная цель исследования — определить оптимальные стратегии предоставления скидок для различных сегментов клиентов с учетом их влияния на прибыль и удержание.

## Результаты анализа
### Для корпоративных клиентов
Рекомендуемые скидки: 0-20%

Исключить: скидки 21-40% (не выходят в плюс)

Допустимы: скидки >=41% только на праздничные акции или оптовые закупки

### Для частных лиц
Рекомендуемые скидки: 0-20%

Исключить: скидки >=41% (окупаются только к 29-му месяцу)

Требуют осторожности: скидки 21-40% (низкая прибыль из-за малого числа клиентов)

### Для домашних офисов
Рекомендуемые скидки: 0-10% (наибольшая прибыль)

Исключить: скидки >=41% (не окупаются)

Требуют осторожности: скидки 21-40% (незначительная прибыль)
